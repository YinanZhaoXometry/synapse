# Synapse 产品功能亮点（报告/PPT 素材 · 中文版）

> 用途：COMP5241 学科报告与 PPT 的产品素材。速查卡结构：每张卡 = **是什么** → 体验细节 → 为什么好。
> 状态基准日：2026-11-07。出处均给出文件路径，可直接现场打开演示。

---

## 一、定位与组织原则

**一句话定位**：Synapse 是双语（中/英）AI 引导的学习平台——**系统给计划、用户自带材料、掌握度只认证据**；目标是让「我认为我会了」变成「我证明我会了」（100% = 可进考场/面试）。

### 三条产品原则

1. **系统给计划，不给内容**：平台永远不提供学习材料，只生成结构化的学习路线；用户把自己的 PDF/Markdown/PPT 挂到节点上。知识的所有权在学习者。
2. **掌握度只由证据驱动（evidence-only）**：用户「标记已掌握」（claim）**永远不改变分数**，只有测验证据改变分数——分数不是自我感觉，是被验证过的状态。
3. **AI-only 单模式**：没有「手动/AI」双轨对比，AI 引导是产品的唯一形态，所有功能围绕它设计。

### Plan-centric：一切围绕学习计划展开

**结论：学习计划既是前门也是组织中枢——材料挂载、节点映射、测验、闪卡、错题、复习调度、每日建议，全部按计划组织。**

- 前门 `/plans` 就是计划列表（不是仪表盘）；侧栏四聚合 hub（错题/今日/闪卡/测验）全部按计划归属分组。
- 材料必须挂到计划的**节点**上才有意义：出题、快测、掌握分全部落在节点维度；单个材料可 pin 到一个节点或 widen 到多个节点（映射覆盖面板可视化）。
- **Study Task 是轻量侧门**：只想搞懂一份文档、不需要计划？直接建任务进阅读器——但保留「升级为计划」的通道（节点 id 稳定、历史证据连续）。

### 贯穿全局的「诚实设计」哲学

- **反 engagement 表演**：不弹「你真棒」式 engagement toast、不显示学习时长、不做积分等上瘾机制（UX 脊柱的反模式清单明文禁止）。
- **无死按钮**：没材料时快捷动作变灰但**点击会 toast 解释原因**，而不是无响应。
- **空态指路**：每个空状态都告诉用户下一步去哪（如 AI Tutor 无计划时诚实指路而非假回复）。
- 语气即品牌：「可以进考场了。/ Ready.」「看了答案 = 放弃此题 · 已记入错题」。

## 二、核心用户旅程（十步流线，可作 demo 剧本）

`docs/demo-script.md` 的十步：**前门（空态创建对话）→ 挂材料 → Reader 旗舰（选择条/标记/标注/Companion 引用）→ 快测闭环（错题入本、掌握分可见移动）→ 整卷 Quiz → 四大 hub → 广场 fork → 笔记+弱项加强 → 任务升级计划 → Settings（数据导出/双语/三调色板+暗色）**。

## 三、功能亮点速查卡

### 3.1 前门双态（Plans Home）

- **是什么**：`/plans` 首页按「新用户/回访用户」呈现两副面孔。
- 体验细节：空态 = 创建对话就是主界面 + Study Task 推介条（「只想搞懂一份文档？不需要计划」）；回访态 = **Continue Hero**（最近计划 + 掌握环 + 「上次读到 Lecture 4」的**跨材料继续阅读线**，一键回到断点）+ 计划卡片（rollup 百分比、节点状态微型条、fork 出处角标）。
- 为什么好：回访第一屏永远回答「我上次学到哪、现在该干嘛」；零任务时整个区块不渲染——不出现空壳 UI。

### 3.2 创建计划对话

- **是什么**：输入主题 → AI 流式输出结构化提案（打字机光标）→ 阶段分组的结构卡 → 一键建计划。
- 体验细节：节点标题**行内点击改名**（重名节点可独立改）；「重新生成」换整套提案；4 个命名目标 chip（备考/深入/复习/练习，可自由文本覆盖）；创建步即可选私有/公开可见性（含披露文案）。
- 为什么好：把「填表单建计划」变成「和 AI 对话拿到草案再微调」——AI 给骨架，人掌握最终决定权。

### 3.3 Roadmap 交互图谱

- **是什么**：计划主页默认以**图谱视图**呈现学习路线（可切回列表）。
- 体验细节：自研 SVG DAG——泳道阶段列 + 交叉数排序 + 正交箭头（815 行组件，**零外部图库依赖**）；可选节点虚线框+「可选」标记；阶段色带显示「已掌握/总数」；顶部进度条；`?node=` **深链**自动选中+平移入视野+开侧栏；**键盘漫游**（方向键列内/跨列移动、Enter 开详情、Esc 关）；缩放 0.5–2（按钮+滚轮+**双指 pinch 连续缩放、锚定手势中点**）；详情用侧 Sheet 保持画布可见。
- 为什么好：学习路线第一次成为可探索的对象而不是一列 checkbox；键盘/触屏/鼠标三通道齐备。

### 3.4 广场与一键改编（fork）

- **是什么**：前门第二 tab 浏览公开计划，一键 fork 成自己的计划。
- 体验细节：卡片展示主题/目标/节点数/阶段；fork 后永久署名「改编自公开计划」；无 demo 数据、空态诚实。
- 为什么好：好计划成为可复用资产；披露透明（FR-38）。
- 注：roadmap.sh 内容导入因**版权许可**主动判不做（WONTFIX），外跳链接保留——范围纪律本身也是产品决策。

### 3.5 Reader 阅读器（官方「旗舰」）

- **是什么**：材料阅读中枢，PDF / Markdown / PPTX（走 markdown 管道，挂载时 toast 声明「仅文本」）三种格式全客户端解析。
- 体验细节：
  - 极简顶栏：返回/标题/**页码 pager**/面板折叠/沉浸模式；
  - **三档响应阶梯**：桌面右侧 dock（可收成 rail）→ 平板右滑出层+scrim → 手机底部 bottom sheet（带拖拽把手，下滑 >80px 关闭且不打断输入框）——同一个 Companion 面板三种容器形态；
  - **阅读位置记忆**：PDF 按可见页、Markdown 按章节 scroll-spy；防抖持久化+卸载兜底；打开时 `?page=N` / `#section` 锚点优先，否则恢复存档位置；
  - 解析失败双语原因 + 重试；重载后字节缺失 → presigned GET 恢复服务器副本 → 再不行引导重传。
- 为什么好：阅读是学习平台的核心停留面，「接着上次读」零成本。

### 3.6 划词选择条：选中即问、当场出题

- **是什么**：正文选中任意一段 → 浮动选择条给出三组动作：**问 Companion**（引用所选文本提问，用户看得到带了什么上下文）/ **快测**（当场出题）/ **标注**（4 色高亮 + 下划线）。
- 体验细节：mousedown 抑制保证点按钮不丢选区；快测有**诚实闸门**——材料没有已确认的节点映射时按钮隐藏、只留提示行「关联节点后可快测」；快测 session id 进 URL，刷新可续；答错自动入错题本并带来源章节，证据归到映射节点。
- 为什么好：**当场加深印象**——读到任何一段，立刻可以「问它、考自己」，把被动阅读变成主动检索练习；且与计划/任务流走完全相同的 QuizRunner，证据口径统一。

### 3.7 高亮 → 生成：让标注变成产出

- **是什么**：两条「从高亮生成内容」的链路。
- 体验细节：
  - **Study Focus 要点面板**（FR-17）：由标注生成 AI 学习要点集，条目**深链回原文**（滚动+闪烁）；空态分级诚实（先去高亮 → 有标注再生成）；重新生成带 vN 版本 chip；
  - **学习笔记**（FR-22）：范围选择器（整计划/选节点/选资料）+ 薄弱点加强开关（服务端按弱项靶向出题）+「在指定位置加插图」自由批注；笔记详情带靶向溯源条（节点标题+覆盖占比）；可**导出 `.md`**（Blob 下载，标记原样保留）。
- 为什么好：用户的高亮不再是死数据，而是二次加工的原料——「我划的重点」直接长成要点集和笔记。

### 3.8 掌握标记 + 确认小测（claim 的诚实闭环）

- **是什么**：悬停 Markdown 章节标题 → 「标记已掌握」→ 该节开头染绿。
- 体验细节：绿色态内嵌**确认小测**按钮（需节点映射）；**claim 永不动分数**——想真到 100%？去答由证据支撑的题。
- 为什么好：把「自以为会了」显式建模成两步（声明 + 验证），产品的核心诚实契约在这里可见。

### 3.9 标注系统（4 色 + 下划线）

- **是什么**：持久化的多色高亮/下划线体系（FR-16）。
- 体验细节：**CSS Custom Highlight API 优先、wrapped-mark 兜底**双渲染路径；列表面板行点击经锚点通道滚动+闪烁定位、可删除；**悬停已涂标注 → popover 显示原文 + 移除**；漂移/丢失范围标「原文已变化」徽章——**绝不静默错位**。
- 为什么好：标注是重阅读器的刚需，而「文本变了之后诚实告知」是大多数阅读器做不到的。

### 3.10 AI Companion（阅读伴侣）

- **是什么**：阅读模式与计划模式双形态的 AI 陪读，服务端流式输出。
- 体验细节：
  - **页感知接地**：按「发送时刻」的阅读位置接地（接地徽章 + 发送闸门），回答自带引用；
  - **提示阶梯**：hint → 分步讲解 → 答案；「直接看答案」常驻可越级——引导优先，但直达答案永远可达；
  - **CitationChip**：「📎 第 7 页 · 12.2 集成策略」点击**页内滚动 + 引用色闪烁**（1.2s），键盘可聚焦，无路由跳转；
  - **考考我出题块**：回复内嵌交互题目（选择题单选 / 简答题关键词覆盖判定，0 命中只说「再试」不判错）；提交后锁定并揭示答案/解析；**提交前 DOM 中不存在答案**（NFR-8，渲染测试强制）；重载后重解析恢复交互；
  - 意图 chip（解释/考我/总结/分析错题）**常显**、busy 时禁用；「分析我的错题」回合锚定该错题源章节；
  - 失败中性 toast + 一键重试且草稿保留；线程持久、重载可复原。
- 为什么好：AI 不再是悬浮的聊天窗，而是「知道你在读哪一页、错哪一道题」的上下文陪读。

### 3.11 Quiz：为「证明掌握」设计的测验

- **是什么**：Open（开放题）/ Choice（选择）/ Mix 三模式，范围可选整计划或本材料，题目严格从用户材料生成。
- 体验细节：一次一题 + 「Q 3/8」进度；**尝试闸门**（提交/弃题前不渲染任何答案）；✦ 提示按钮**免费**但只给源章节标题级提示（不泄答案）；弃题=「看答案」**记错进错题本**；选择题 1–4 数字键选择、Enter 确认/下一题、Esc 二次确认退出；开放题「对照材料评分中」shimmer → 判定+理由+引用；**判定节奏由用户掌控**（机器已前进但 UI 钉住直到按 Enter）；会话恢复诚实标注「从第 1 题继续」；结果页有每题分解（判定/理由/来源摘录）+ 受影响节点掌握分变动 + 错题列表 + 「再来一轮」（服务端铸**新** session，绝不重放已判答案）；`/quiz` hub 支持历史查看 + 行级 Retake（按原范围+模式重开）。
- 为什么好：把「测验」做成了证据采集仪式——每道题的答案、放弃、提示行为都有明确的产品语义，且全部汇入掌握分与错题本。

### 3.12 Flashcards：先回忆，后验证

- **是什么**：从材料生成的闪卡 + 自评复习。
- 体验细节：Space/点击翻面、←→ 导航、Esc 退出；**背面翻面前不在 DOM**（先回忆后验证，渲染测试强制）；难/中/易三档自评**即时落库**（刷新丢队列但永不丢评分）；重访总先显正面；结束摘要含评分分布 + 「再学一轮」（同一队列重开，非重新生成）；**自评不产生证据**（与 ADR-0001 一致）；`/flashcards` hub 跨计划聚合全部卡组、深链进入流内学习——hub 永不生成。
- 为什么好：闪卡的心理学本质是主动回忆，UI 契约（答案不提前渲染）用测试锁死了这个本质。

### 3.13 错题本（Mistakes hub）

- **是什么**：全部错题（选择+开放+弃题）按计划/任务分组的管理面（FR-23）。
- 体验细节：每卡带题干、你的答案、节点 chip、日期、**源章节深链**（锚点通道直达原文）、「再测」（节点级快测）；**resolve 生命周期**——手动标记已解决（双向 toggle），已解决卡变淡仍可读，可按 open/resolved 过滤。
- 为什么好：错题不是耻辱柱而是待办清单；每道错题都能一键回到「它出自原文哪里」。

### 3.14 今日学习（Planner）

- **是什么**：每日任务面（FR-27）：到期复习 + 手动任务 + 弱项推荐。
- 体验细节：到期 re-queue（错题/闪卡两类）**深链到完成它的那个流**——没有内联「标记完成」开关，完成=产生新证据；v1 启发式弱项推荐卡（「按掌握度推荐 · v1」标签常驻，不冒充 AI）；**按需「生成 AI 建议」**——显式触发才调 AI，同一 (用户, 计划, UTC 日) 确定性 uuid：同日重新生成免费重放，AI 日上限到了有诚实禁用文案；14 天一致性周条带（有证据日变实心、安静日空心、窗外虚线）。
- 为什么好：每日清单不靠「打卡」驱动而靠证据驱动；AI 用量对用户透明可控。

### 3.15 Study Task：单文档直通 + 升级通道

- **是什么**：第二扇门——上传一份文档直接进阅读器，零计划 UI。
- 体验细节：上传校验（PDF/MD ≤20MB，PPTX 走 md 管道带提示）→ 幂等挂载 → 自动建单节点任务 → 立即解析 → 跳阅读器；创建失败重试**复用同一 material**（不产生孤儿）；单材料孪生主页（掌握环=其节点服务端分）；**「升级为计划」确认对话框**（节点 id 稳定、证据连续性有 spec 证明）。
- 为什么好：尊重「我今天只想读一份讲义」的真实场景，同时保留成长路径。

### 3.16 十大 hub 页全部真数据化

- **Dashboard**：按时段问候（zh 早/午/晚）、服务端连续天数、4 张 KPI 卡各深链对应 hub、本周目标环（当前 ISO 周、封顶 100% 不外推）、最近徽章条。
- **Materials**：服务端全量列表（类型/大小/parse 状态 chip，失败才强调+原因 tooltip）、归属 chip、类型过滤+搜索；上传按钮是「到计划里挂载」的诚实指针。
- **Analytics**：三条真实序列——**节点掌握度横条（最弱排最前）**、8 个 ISO 周答题准确率趋势、14 天学习一致性条带。
- **Achievements**：12 徽章服务端状态（锁定显示进度「1 / 5」封顶）、非仅色状态编码、会话内新解锁一次性 confetti toast（关动效时降级纯 toast）。
- **AI Tutor**：退役假回复，改为计划选择器 + 真 plan-grounded CompanionPanel。
- 为什么好：脚手架时代的十页 mock 全部换成服务端真数据——「没有一页是演示用的假屏幕」。

### 3.17 视觉与设计体系

- **是什么**：Northstar 视觉体系——在 OpenDesign 中选定 **Arc 浏览器 design system** 产出视觉真源，经 12 节映射落地为 **167 个 CSS 变量 / 8 组 token**（含玻璃体系、品牌渐变、**学习状态语义色**：mastered/partial/citation/标注四色）。
- 体验细节：**3 调色板**（sunset 珊瑚默认 / twilight / aurora）× **3 模式**（system/light/dark，system 实时跟随系统）；运行时改写 CSS 变量热切换（hex→HSL 换算）；**暗色下 accent 自动提白 14%/30%** 保证对比度；字体 Source Serif 4（display）+ Inter（body）；动效词汇表 10 组 keyframes（pop/slide-up/pulse-glow/reader-flash/sheet-up/confetti…），每个动效注释出处决策号；claudette（MIT）阅读皮肤可选开关。
- 为什么好：三调色板×深浅=6 种外观即时可换且全局一致；「学习状态有专属语义色」让掌握度在界面各处可被颜色语言直接阅读。

### 3.18 i18n 双语

- **是什么**：全文案中英双语，**904 个词条 × 2 语言全表平价由专门测试钉死**（缺一边 CI 红）。
- 体验细节：`t(key, {var})` 插值；切换即时生效不刷新、持久化、同步 `<html lang>`；**非 React 侧镜像接口**让服务端 AI 适配器生成同语言的题目/闪卡。
- 为什么好：双语不是「翻译过的界面」而是受测试契约保护的产品属性；AI 输出语言跟随界面语言。

### 3.19 触屏优化批次

- **是什么**：Roadmap 画布**双指 pinch 连续缩放**（0.5–2，锚定手势中点，双指平移同数学导出）+ 移动导航抽屉**滑动关闭**。
- 体验细节：抽屉阈值 min(40% 宽,120px)、动效门控 240ms 回弹；`touch-action:pan-y` 保住原生竖向滚动；指针捕获在**手势确认时刻**才抓——不吞点击；入场动画每个打开会话只播一次。
- 为什么好：平板/手机上「能用」升级为「好用」，且修复了 W3C pointerevents 已知缺陷在本项目的落地姿势。

## 四、效率与易用性

**结论：高频操作全部有快捷通道——⌘K 全局指挥中心、即时主题切换、全套键盘操作。**

- **⌘K Command Center**：全局 ⌘K/Ctrl+K 呼出命令面板（Northstar 交互）：**全部页面目的地 + 设置的快速导航**、**中英文即时切换**，模糊搜索即达（`frontend/src/components/shared/CommandPalette.tsx`）。
- **主题与夜间模式快速切换**：Settings 里 3 个调色板渐变圆片 + 深浅模式（含跟随系统）+ reduce-motion 开关，**点击即时全局生效、不刷新页面**，偏好持久化（`frontend/src/pages/SettingsPage.tsx`）。
- **键盘整体可达**：Quiz 数字键 1–4 + Enter 全键盘作答；Roadmap 方向键漫游；Esc 全局关闭顶层；⌘K 导航——键盘用户可以几乎不碰鼠标完成核心学习流。
- **统一的 toast 语言**：sonner 单一 toast 模式，错误码 → i18n 文案 → toast 的固定管线，没有各说各话的报错。
