# docs/product/

BMAD product artifacts. `/bmad-product-brief` and `/bmad-prd` workspaces live here, one directory per run following the `brief-{name}` / `prd-{name}` convention (e.g. `brief-synapse/`, `prd-synapse/`), each holding the main doc, its `.memlog.md`, and any addenda.

Consumer rule: read the relevant brief here before `/grill-with-docs`, `/to-spec`, or `/to-tickets` on a new feature. See [docs/agents/workflow.md](../agents/workflow.md).
